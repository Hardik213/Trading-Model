## Demonstrated gap and correction

The audit found one conformance gap in the supplied-evidence validation path: `_validate_visible_break_and_follow_through()` previously compared a supplied break with the first close beyond the structural point globally. That rejected a valid later break even when the earlier candidate had been invalidated by a close back through the point. The visible derivation path already skipped invalidated candidates, so the two paths disagreed.

The minimal correction makes the validator identify the first non-invalidated eligible break, while still rejecting a supplied break whose own follow-through window is invalidated. The regression test `test_mss_accepts_later_break_after_an_earlier_candidate_is_invalidated` demonstrates the corrected behavior.

## Status and limits

- **Implementation conformance:** The audited clauses are represented by source checks and focused synthetic tests listed above; the demonstrated later-break discrepancy is corrected.
- **Canonical integration:** `evaluate_core_v1_pipeline()` derives MSS through `evaluate_core_v1_mss(..., derive_visible=True)`, then revalidates the supplied MSS evidence before later stages. Unresolved MSS returns a developing/incomplete pipeline result and does not advance later gates as a valid hypothesis.

- **Strategy acceptance:** Not assessed. This audit does not establish predictive value, trading suitability, or acceptance of the ICT rule.
- **Performance evaluation:** Not performed. No market replay, backtest, outcome calculation, metrics, charts, or sealed-2025 material was accessed.
- **Remaining blocker:** The contract is a development implementation rule, not a frozen evaluation build; broader strategy and runtime freeze gates remain outside this audit.
